CodSoft Data Science Internship Projects

This repository contains three projects completed for the CodSoft Data Science Internship.

Task 1: Titanic Survival Prediction

This project predicts whether a Titanic passenger survived using machine learning.

Python file: "Task1_Titanic/titanic_survival.py"

Task 3: Iris Flower Classification

This project classifies Iris flowers into three species: Setosa, Versicolor, and Virginica.

Python file: "Task3_Iris/iris_classification.py"

Task 4: Sales Prediction Using Python

This project predicts sales based on advertising expenditure using Linear Regression.

Python file: "Task4_Sales/sales_prediction.py"

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

Installation

Install the required libraries using:

"pip install -r requirements.txt"

Running a Project

For example, run the Iris classification project using:

"python Task3_Iris/iris_classification.py"

Note: The Titanic and Sales projects require their respective datasets. See each task's README file for details.
