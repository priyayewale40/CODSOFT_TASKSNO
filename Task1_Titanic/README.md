# Task 1 — Titanic Survival Prediction

## Objective
Build a classification model to predict whether a Titanic passenger survived.

## Dataset
Download the training CSV from https://www.kaggle.com/competitions/titanic/data and save it here as `train.csv`.

## Run
From the repository root:

```bash
pip install -r requirements.txt
python Task1_Titanic/titanic_survival.py
```

The script expects the common Kaggle Titanic columns, including `Survived`, `Pclass`, `Sex`, `Age`, `SibSp`, `Parch`, and `Fare`.
